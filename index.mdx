## The APIs

| | Messaging API | Publishing API | Link in Bio API |
| --- | --- | --- | --- |
| Covers | Contacts, tags, segments, conversations, messages, broadcasts, automations, media | Social accounts, posts, scheduling, approval, tags, media, analytics | Bio pages and blocks, short links, QR codes, pixels, form submissions, analytics, custom domains |
| Base URL | `https://app.onlysocial.io/api/v1` | `https://app.onlysocial.io/os/api/{workspace-uuid}` | `https://app.onlysocial.io/api/v1/biolinks` |
| Workspace | Chosen by the API key | In the URL, and must match the API key | Chosen by the API key |

One workspace API key can call every API, as long as you give it the permissions for each when you create it.

<Note>
Some features depend on your plan. If an endpoint returns `404` even with a valid key, the feature is not included in your workspace's plan.
</Note>

<Tip>
Integrated before October 2026? Your personal access token still works on the Publishing API at the same addresses. See [Older credentials](/authentication#older-credentials).
</Tip>
